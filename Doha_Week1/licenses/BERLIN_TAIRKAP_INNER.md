# Ta-ir-kap — Inner Coffin

Object: ÄM 4, Egyptian Museum and Papyrus Collection, Staatliche Museen zu Berlin.

3D data: Matthias Lang and Philippe Pathé / University of Bonn, BCDH.

Lid: https://doi.org/10.60507/FK2/I9MDEV
Base: https://doi.org/10.60507/FK2/LIQ3SG

The dataset catalog specifies CC BY 4.0. The accompanying source README specifies CC BY-SA 4.0 for the individual datasets and documentation. Both statements are retained here; MuseAI distributes these derivatives under CC BY-SA 4.0, including its attribution and share-alike requirements.

Changes: joined the matching lid and base without changing their shared source coordinates, simplified each part to approximately 65,000 triangles, reduced textures to 2048 px, exported a self-contained GLB, and uniformly scaled the object for a horizontal museum display. No generic base or invented coffin shell was added. Preview images are renders of this derivative.
